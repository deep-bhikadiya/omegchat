# 🌐 OmegChat  
👉 [Live Demo](https://omeg.chat)  

OmegChat is a **random video chat application** inspired by Omegle.  
It connects strangers in real-time using **WebRTC** for peer-to-peer video and **Socket.IO** for signaling.  

🚀 Features:  
- 🔗 Randomly connect with strangers  
- 🎥 Real-time video streaming (WebRTC)  
- 💬 Live text chat alongside video  
- 🔄 "Stop & Find Another" button to quickly switch partners  
- 📱 Mobile responsive & desktop-friendly layout  
- ⚡ Powered by **React**, **Node.js**, **Express**, and **Socket.IO**  

---

## 🛠️ Tech Stack  

**Frontend:**  
- React.js  
- WebRTC (video/audio)  
- CSS (responsive design)  

**Backend:**  
- Node.js  
- Express.js  
- Socket.IO (signaling server)  

---

## ⚙️ Setup & Installation  

### 1️⃣ Clone the repo  
```bash
git clone https://github.com/your-username/omegchat.git
cd omegchat
```

**Frontend:**  
```bash
cd client
npm install
npm start
```

**Backend:**  
```bash
cd backend
npm install
npm start
```
